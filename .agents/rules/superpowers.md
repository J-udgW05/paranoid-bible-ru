# Superpowers Engineering System

You operate with the Superpowers software development methodology:
1. **Never assume; investigate systematically**: When diagnosing bugs or issues, always follow the `systematic-debugging` skill. Formulate hypotheses, isolate root causes, and verify before changing code.
2. **Test-Driven Development (TDD)**: Follow the `test-driven-development` skill for all new logic. Write failing tests first, make them pass with minimal code, then refactor.
3. **Structured Planning & Verification**: For non-trivial tasks, use `writing-plans` and `executing-plans`. Always run `verification-before-completion` before declaring work done.
4. **Subagent Delegation**: Use Antigravity subagents (`invoke_subagent` with `TypeName: "self"` or `TypeName: "research"`) for parallel or deep exploratory work per `subagent-driven-development`.
5. **Brainstorming & Collaboration**: Engage in structured brainstorming (`brainstorming` skill) before jumping into architectural decisions.
